# K·Ü·N·Y·E — Akademik İzlerin Akıllı Takipçisi

Üniversite akademisyenlerinin yayın kayıtlarını ORCID, Crossref ve 
Google Scholar ile karşılaştırır; eksikleri otomatik mail ile bildirir.

## Kurulum (Windows x64)

1. Aşağıdaki **Releases** sekmesinden en son sürümü indirin
2. `Künye Setup x.x.x.exe` dosyasını çalıştırın
3. `C:\Program Files\Künye` altına kurulur

## Sistem Gereksinimleri
- Windows 10/11 (64-bit)
- Google Chrome (Scholar araması için)
- İnternet bağlantısı

## Özellikler
- YÖKSİS'ten otomatik personel listesi çekimi
- ORCID, Crossref, Google Scholar entegrasyonu
- Eksik yayın tespiti ve kişiselleştirilmiş mail bildirimi
- Hızlı Sorgu: tek akademisyen anlık sorgulama
- Otomasyon: zamanlanmış otomatik tarama
- Şifreli lokal veritabanı (tarama geçmişi güvenli)
